# مواصفات v0

## السؤال

هل يساعد تمثيل عربي صريح، مع إبقاء المسار السطحي، على تعميم أفضل على صيغ صرفية قليلة الظهور تحت ميزانية ثابتة؟

## النطاق

- causal language model صغير.
- فصحى حديثة مع طبقة تراثية محدودة.
- baseline سطحي أولًا، ثم ablations معزولة.
- لا جمع ويب واسع ولا تدريب موسع قبل بوابة Go.

## القيود

- البيانات المرخّصة فقط.
- raw corpora خارج Git.
- كل release وrun يحمل hash للمدخلات والإعدادات.
- test النهائي لا يستخدم لاختيار البيانات أو الأوزان.

## معيار v0

يمكن بناء dataset manifest، تشغيل pipeline حتمي، تسجيل run مكتمل، وإعادة إنتاج نفس النتائج في اختبارات الوحدة والتكامل.
