# ADR 0001: أساس Python حتمي خفيف

## القرار
نبدأ بطبقات Python قياسية typed قدر الإمكان، مع schemas immutable نسبيًا، وبدون إطار تدريب أو tracker خارجي في milestone التأسيسي.

## السبب
المستودع فارغ وبيئة التشغيل الحالية لا تثبت توفر runtime أو مكتبات ML. تثبيت العقود والـlineage أولًا يقلل المخاطر ويجعل إضافة framework لاحقًا قرارًا قابلًا للقياس.

## الأثر
يمكن تشغيل الاختبارات الأساسية دون GPU أو تنزيلات خارجية. ستضاف تبعيات التدريب بعد نجاح baseline contract وقرار موارد صريح.
