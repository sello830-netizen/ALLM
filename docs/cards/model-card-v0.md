# Model Card v0

## الحالة

يحتوي الإصدار الحالي على bigram reference baseline مستقل عن GPU لاختبار pipeline فقط. لم يبدأ baseline neural training قبل تثبيت موارد التشغيل وإطار ML.

## متطلبات الإصدار

- parent model وdataset release وtokenizer وevaluation versions.
- code revision وconfig hash وseed.
- مقاييس الطلاقة والتعميم والتكلفة.
- القيود المعروفة ومخاطر الاستخدام.
