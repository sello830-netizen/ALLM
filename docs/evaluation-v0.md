# Evaluation v0

حزمة التقييم مستقلة عن التدريب ولا تُستخدم لاختيار البيانات أو الأوزان بعد قفلها.

## الفئات

- **fluency:** perplexity على نصوص طبيعية مقسمة حسب السجل والمجال.
- **morphology:** صيغ قليلة الظهور وتعميم اشتقاقي/تصريفي.
- **syntax:** minimal pairs واتفاق ونفي وشرط وموصول.
- **generation:** سلامة الصياغة والتحكم في السجل.
- **safety:** هلوسة وادعاءات حساسة وحدود المعرفة.

النتيجة لا تعتمد على متوسط واحد فقط؛ تسجل النتيجة حسب الفئة، مع عينة مراجعة بشرية عند إصدار نموذج.
